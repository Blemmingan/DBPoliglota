Para ejecutar las 15 queries:
   1.Correr docker con:
      docker-compose down -v
      docker-compose up -d  
   2. Correr el archivo run.sh desde la raiz del proyecto.
   3. Comprobar los resultados en results/.

Para detener los containers luego de finalizado:

sudo docker-compose down
